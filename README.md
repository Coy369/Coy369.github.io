# Coy369 portfolio starter

This is a static HTML/CSS starter for a GitHub Pages portfolio. Replace each square-bracket prompt with your own accurate details and writing before publishing.

## Publish with GitHub Pages

1. Sign in to GitHub as `Coy369` and create a **public** repository named `Coy369.github.io`.
2. Add `index.html` and `styles.css` to the top level of the repository. Keep their names unchanged unless you also update the link in `index.html`.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)` and save.
4. Wait for the deployment to finish, then open `https://coy369.github.io` and check it on a phone and computer.
5. Submit the live website link through the Turnitin submission process in your assessment.

GitHub Pages makes the site public. Do not publish an ID number, home address, private contact details, or anything you would not want visible online. You may add professional contact information if you choose.

## Before submitting

- Replace all `[square-bracket prompts]` with your own work; remove any prompts that remain.
- Include the required two reflections, CV, skills/projects, application letter, and email template.
- Check that images and any CV attachment are suitable for public viewing.
- Open every link and confirm the site loads without a GitHub sign-in.
- Follow your course's rules for acknowledging AI assistance.
